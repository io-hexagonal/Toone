## One place to shape and run agentic work

Toone is a native workspace for projects that use AI agents. A project keeps the agents you work with, the routines they can run, the tools they use, and the knowledge they build in one understandable place.

You can begin with one agent and one useful task. As the project grows, agents can specialize, routines can call other routines, and work can move between roles without turning into one untraceable conversation.

## The operating loop

Most work in Toone follows the same loop:

1. **Define your agents.** Give one or more agents a clear purpose, explain what each is responsible for, and describe how they should approach the work.
2. **Shape the process together.** Talk through repeatable work with an agent, then turn that conversation into a routine written in natural language.
3. **Run and observe it.** Follow the work while it happens and inspect where it slows down or fails.
4. **Keep the result.** Outputs, project files, and useful context remain available for the next run.

This makes Toone useful both for direct work with an agent and for processes that should run the same way again.

## What lives in a project

A project is the boundary around your work. It can contain specialized agents, repeatable routines, connected tools, readable files, and accumulated knowledge. Those parts remain related instead of being scattered across unrelated chats.

The project begins as simply as you need. You do not need a large agent team or a finished automation plan before starting.
