## Extend what agents can do

MCP servers provide structured tools beyond Toone’s native project surface. Enable the servers a workflow needs and provide required credentials without embedding secrets in routine instructions.

## Choose the scope

Global MCPs are available across projects on the Mac. Project-specific tools belong with the project that needs them, keeping capabilities from appearing everywhere by default.

## Reuse browser integrations

Browser site maps describe repeatable interactions with a web service. Promote a useful map to the global collection when several projects should be able to use the same browser integration.

## Keep access deliberate

An enabled tool expands what an agent can reach or change. Match each MCP and browser integration to a defined agent responsibility, and disable global capabilities that are no longer needed.
