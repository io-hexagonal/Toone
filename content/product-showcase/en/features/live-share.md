## Share the working project

Live Share lets another person enter the context where the work is happening. Instead of sending disconnected transcripts or screenshots, collaborators can follow the relevant agents, threads, files, and presence together.

## Begin with visibility

Shared access begins read-only by default. A collaborator can understand the state of the project before the host decides whether broader interaction is appropriate.

## Expand access deliberately

The host controls when access grows beyond observation. This keeps collaboration useful without making an invitation equivalent to unrestricted control over the project.

## Follow work as it changes

Presence makes it easier to see where another person is working and what part of the project they are reviewing. This is especially useful while an agent or routine is operating live and both people need the same frame of reference.

Live Share is currently presented as a beta capability.
