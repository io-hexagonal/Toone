## See when work is supposed to happen

The Calendar places scheduled routines and ordinary project events on the same time-based surface. Move between day, week, and month views depending on the planning horizon you need.

## Routine schedules

Scheduled routines appear as read-only events derived from their routine definitions. This makes the operating schedule visible without turning Calendar edits into silent changes to a routine.

## Project events

Create and edit project events directly in the Calendar. Events can include timing, participants, tags, and confirmation status, while proposed events can remain pending until someone confirms them.

## Keep schedule and execution distinct

The Calendar explains when work is expected. Use Current Routines and background threads to understand what is actively running and how it is progressing.
