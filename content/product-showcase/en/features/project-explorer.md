## Keep the project beside the conversation

Project Explorer is the right-side panel of the Toone workspace. It keeps the active project folder visible beside agents and threads so the files being discussed remain part of the same working surface.

## Browse project files

Expand the Project section to navigate the folder tree and open readable files. The panel follows the active project selected in the project switcher.

## Open or change a project folder

If no project is active, Project Explorer is also the starting point for selecting one. Use its folder control later when you want to open or create work in a different directory.

## Make room when you need it

Hide or reveal Project Explorer from the panel header. Closing the panel changes the layout without closing the project or its active agent work.
