Toone can stay compact when you need a nearby agent and expand into a full workspace when a conversation becomes a larger piece of work. A quick question can turn into a deeper investigation without opening a separate window or starting a new conversation.

## Window size and panel layout

Settings provides five arrangements for the chat and Project Explorer panels:

- **Full Height** uses the visible height of the screen.
- **Compact** keeps an offset around panels and uses less vertical space.
- **Docked** places chat at the bottom center with Project Explorer beside it.
- **Zen** gives chat two thirds of the screen and Project Explorer the remainder.
- **Spotlight** centers a minimal chat panel and hides Project Explorer.

The same project and conversation remain active when the panel layout changes.

### Fit other applications around Toone

Toone can resize ordinary application windows into the space left around its panels. By default, those windows return to their previous frames when Toone is hidden; you can keep the fitted layout instead. Fullscreen, minimized, and subsequently repositioned windows are left alone.

### Choose a panel style

Panel styles change color, contrast, and transparency. On the macOS 26 build, native material and tint controls provide additional visual tuning.

## Project switcher

The project strip appears above the main workspace when multiple projects are enabled. Each project has a numbered pill, so its active agents, threads, and files stay one short switch away.

### Add and remove projects

Use the plus control to select another project folder. Toone keeps up to nine workspaces in the strip. Closing an inactive entry does not delete its project folder.

### Switch by number

Use the Option-number shortcut shown on each pill to move directly to that project.

### Notice activity elsewhere

An inactive project pulses when it has unread agent activity, so you can stay on the current project and still see that another one needs attention.

During a remote Live Share session, the same strip switches between the projects the host has shared.

## Project Explorer

Project Explorer is the right-side panel of the workspace. It keeps the active project folder visible beside your agents and threads.

### Browse project files

Expand the Project section to navigate the folder tree and open readable files. The panel follows the project selected in the project switcher.

### Open or change a project folder

If no project is active, Project Explorer is where you select one. Use its folder control later to open or create work in a different directory.

### Make room when you need it

Hide or reveal Project Explorer from the panel header. Hiding the panel changes the layout without closing the project or stopping its agent work.

## Zen mode

The Zen layout above sizes the panels. Zen mode is a separate setting that turns the desktop behind them into an ambient video.

### Choose the video

Select an ambient video in Settings before you turn on Zen mode. The video becomes the background for the panel workspace, and the choice stays for the next session.

### Enter and leave

Toggle Zen mode from Toone or with its global shortcut. Press Escape to leave it and return to the ordinary desktop.

### Control the audio

When the video has audio, mute or unmute it from the Toone menu without leaving Zen mode.
