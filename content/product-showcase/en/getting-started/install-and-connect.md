## Before you begin

You need a supported Mac and access to either OpenAI Codex or Anthropic Claude. Toone does not bundle a separate model account; you choose and authenticate the provider you want to use.

```toone-ui
settings-default-model
```

## Install the app

Download the build that matches your version of macOS, open it, and follow the setup flow. Keep Toone available in the Dock while you learn the workspace.

```toone-ui
setup-route-choice
```

## Connect your provider

Choose Codex or Claude during setup and complete the provider authentication. A project can contain many agents, but you only need one working provider to complete the quickstart.

```toone-ui
setup-provider-cards
```

## Checkpoint

You are ready to continue when Toone opens its project experience without asking you to finish provider setup.

```toone-ui
project-explorer-empty
```
