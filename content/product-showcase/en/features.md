## Experience

### Agent Spotlight

Summon an agent from anywhere and begin without navigating back through the full application.

[Explore Agent Spotlight](/how-to/features/agent-spotlight).

### Workspace windows

Choose how Toone’s panels occupy the desktop, fit other application windows around them, and select the visual style that works for you.

[Explore workspace windows](/how-to/features/workspace-windows).

### Zen mode

Place ambient video behind your Toone panels when you want a calmer, more focused working environment.

[Explore Zen mode](/how-to/features/zen-mode).

### Project switcher

Keep several projects open, switch between them from the numbered strip, and see when an inactive project has new activity.

[Explore the Project switcher](/how-to/features/project-switcher).

### Project Explorer

Browse the active project’s files from the right-side panel and change the project folder without leaving the workspace.

[Explore Project Explorer](/how-to/features/project-explorer).

## Workflows

### Browser sessions

Let agents work through authenticated browser sessions while you retain visibility into the browser context being used.

[Explore browser sessions](/how-to/features/browser-sessions).

### Routines

Turn a process discussed with an agent into a repeatable routine with clear inputs, responsibilities, approvals, and outputs.

[Explore routines](/how-to/features/routines).

### Agent orchestration

Delegate work across specialized agents, run independent tasks in parallel, hand context between roles, and bring results back together.

[Explore agent orchestration](/how-to/features/orchestration).

### Workflow library

Explore reusable workflow packages and bring an approved routine family into a project as a starting point.

[Explore the workflow library](/how-to/features/workflow-library).

### Calendar

See routine schedules and project events across day, week, and month views.

[Explore the Calendar](/how-to/features/calendar).

### Background threads

Keep automated and system work separate from your direct conversations while retaining one place to inspect or stop it.

[Explore background threads](/how-to/features/background-threads).

## Control and safety

### Project History

Use readable checkpoints and a visual timeline to understand what changed in a project and who changed it.

[Explore Project History](/how-to/features/project-history).

### Safe Mode

Screen Claude tool results against forbidden topics before the output reaches a conversation, with fail-closed behavior and an audit log.

[Explore Safe Mode](/how-to/features/safe-mode).

## Connect

### Live Share

Invite someone into a project and follow agents, threads, files, and presence together under host-controlled access.

[Explore Live Share](/how-to/features/live-share).

### Voice and meetings

Talk directly to agents and turn captured conversations into project context, decisions, and follow-up work.

[Explore voice and meetings](/how-to/features/voice-and-meetings).

### Mobile companion

Pair an approved iPhone over the cloud or local network to reach Toone away from the Mac.

[Explore the mobile companion](/how-to/features/mobile-companion).

### MCPs and integrations

Enable MCP servers and reusable browser site maps globally or within the project that needs them.

[Explore MCPs and integrations](/how-to/features/mcp-integrations).

### AI providers

Connect OpenAI Codex or Anthropic Claude while Toone maintains the project structure around the selected provider.

[Explore AI providers](/how-to/features/ai-providers).
