## Statements kept that still need a check

1. **"Toone does not proxy, log, or retain these [AI] requests."** True while `TOONE_REVIEWER_AI_ENABLED=false`. If the reviewer route is turned on, this sentence becomes false. The branch's conditional paragraph would then need to be added.
2. **Relay "end-to-end encryption".** The 2026-09-30 assessment (`docs/audits/2026-09-30-cloud-relay-e2e-assessment.md`, parked in monorepo commit e75d8f01, not on `main`) finds frames are E2E encrypted. It also finds the relay operator could MITM a session (C1 signing oracle, C2 silent key rotation). The sentence was left as it is, but the owner should decide whether it stays until C1/C2 are fixed.
3. **"Toone does not include any crash reporting or diagnostic SDKs."** `project.pbxproj` has no Sentry, Crashlytics, Bugsnag or Firebase. Apple's own opt-in crash sharing for App Store builds is not mentioned.
4. **Website analytics "sets no analytics cookies and does not track you across sites."** The site code loads `analytics.truleaf.org/script.js` only after an allow choice (`components/PrivacyChoices.tsx:41-47`). What that host stores or logs (IP addresses) was not verified.
5. **"Keystrokes, screenshots, or screen recordings"** in the list of things Toone does not receive. That holds for Toone's servers today. Screenshots of built-in browser pages can go to the AI provider (covered by the AI section).
6. **App Store Server Notifications.** The page says the server "can" receive them. Confirm the production notification URL (`POST /v1/app-store/notifications`) is set in App Store Connect.
7. **Stripe.** `apps/toone-server/internal/bootstrap/app.go:495-512` wires Stripe checkout for templates behind `PaymentsEnabled`. The tracked ConfigMap does not set it. If it is ever on, the page needs a payments paragraph.
8. **Google sign-in on the website** loads Google's GIS script (`components/AuthPage.tsx`, `NEXT_PUBLIC_GOOGLE_CLIENT_ID`). The page does not mention it, just as it did not before this update.
9. **Website Apple sign-in end to end.** It needs production `OIDC_APPLE_SERVICES_ID` to contain `com.trytoone.web`. The monorepo runbook (`docs/operations/sign-in-with-apple.md`, "Rollout order" step 2) says it does. Not checked against the live secret.
